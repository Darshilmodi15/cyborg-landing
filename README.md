# 🤖 Cyborg Nexus Landing Page

A futuristic, production-ready cyberpunk landing page built with modern web technologies including **Next.js 15**, **React 19**, **TypeScript**, **Three.js**, **GSAP**, and **Framer Motion**.

Designed to deliver a premium user experience with immersive 3D visuals, smooth scrolling, advanced animations, responsive layouts, and enterprise-grade performance optimization.

---

## ✨ Features

### 🎨 Futuristic Cyberpunk Design

* High-end cyborg-inspired interface
* Immersive neon aesthetics
* Glassmorphism and modern UI patterns
* Fully responsive across desktop, tablet, and mobile devices

### ⚡ Advanced Animations

* Framer Motion powered interactions
* GSAP ScrollTrigger animations
* Smooth Lenis scrolling experience
* Optimized animation lifecycle management

### 🌌 Interactive 3D Experience

* Three.js powered hero section
* React Three Fiber integration
* Drei utilities for enhanced 3D development
* Client-side dynamic loading for improved performance

### 🚀 Performance Optimized

* Next.js App Router architecture
* Dynamic component loading
* Reduced-motion accessibility support
* Optimized rendering and asset delivery

### 🔍 SEO Ready

* Open Graph metadata
* Twitter Card integration
* robots.txt
* sitemap.xml
* Search engine optimized structure

## 🚀 Getting Started

### Clone Repository

```bash
git clone https://github.com/Darshilmodi15/cyborg-landing.git
cd cyborg-landing
```

### Install Dependencies

```bash
npm install
```

### Start Development Server

```bash
npm run dev
```

Open:

```text
http://localhost:3000
```

---

## 📜 Available Scripts

### Development

```bash

```

Starts the local development server.

### Production Build


Creates an optimized production build.

### Start Production Server

## 🌐 Deployment

### Deploy on Vercel

```bash
npm run build
vercel
```

Before deploying to production, update:

```text
src/app/layout.tsx
src/app/sitemap.ts
src/app/robots.ts
```

with your actual production domain.
